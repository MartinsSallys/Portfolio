# Portfólio de Sallys Martins

Portfólio em Astro com projetos de backend e dados, palco 3D em Three.js, capturas estáticas e currículo imprimível.

Com Node 22.23.4 ou superior, execute `npm ci` e `npm run dev`. Gere o site estático com `npm run build`. A saída em `dist/` usa o caminho público `/Portfolio/`.

A consulta de projetos é simulada por padrão. Configure `PUBLIC_API_URL` durante o build para consultar uma API real.
