CASE 01 Alpha de integração

Postais da Parnaíba

Uma experiência editorial para preservar e apresentar a memória histórica de Parnaíba.

Escopo autoral
Frontend público, interações e cliente administrativo
Fontes de dados
Conteúdo local + API externa esperada

O que implementei

  • Site multipágina com conteúdo editorial e acervo visual
  • Slider com navegação por teclado e comparador antes/depois
  • Galeria, timeline e crônicas consumindo contrato HTTP
  • Painel cliente para CRUD de conteúdo e upload de imagens
Decisão técnica

HTML estático para o conteúdo editorial e JavaScript separado para coleções dinâmicas, sem etapa de build.

Limite atual

A API não está neste repositório e usa localhost por padrão; o formulário administrativo ainda precisa de ajuste de validação.

CASE 02 Protótipo backend

BeckGlobal

Um boilerplate para estruturar APIs REST com persistência, configuração e ambiente containerizado.

Escopo autoral
Setup da API, CRUD, modelo, sessão e configuração
Persistência
SQLite atual + PostgreSQL declarado no Compose
Superfície HTTP6 endpoints da aplicação
GET/healthhealth check
POST/users/criar usuário
GET/users/listar usuários
GET/users/{user_id}consultar usuário
PUT/users/{user_id}atualizar usuário
DELETE/users/{user_id}excluir usuário

O que implementei

  • FastAPI, schemas Pydantic e CRUD de usuários
  • Modelo e sessão SQLAlchemy com respostas sem senha
  • Hash bcrypt e primitivas para emissão e leitura de JWT
  • Dockerfile e Compose declarando API e PostgreSQL
Decisão técnica

Separação entre API, core, database e models. As rotas acessam o ORM diretamente, sem services ou repositories.

Limite atual

A migração inicial está vazia, o JWT não protege rotas e ainda não existem testes automatizados ou CI.

  • FastAPI
  • Pydantic
  • SQLAlchemy
  • Alembic
  • Docker
